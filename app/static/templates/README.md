# DPCR Template Folder

Please place your Excel template file here:
* **Filename:** `dpcr_template.xlsx`
* **Path:** `app/static/templates/dpcr_template.xlsx`

The system will use this file as the base format, fill in the cascaded quotas, and output the customized Excel spreadsheet for download when the "Export DPCR (Excel)" button is clicked in the Dean Dashboard.
